# Pactium Verifiable Protocol Model

Pactium is a host-neutral proof-first protocol substrate. The model centers on an Operation Ledger as global ordering authority, a transparency log for ledger proofs, one shared Canonical Prolly Tree based Verifiable Index Engine for state, checkpoint, workspace projection, lifecycle, idempotency, and causality indexes, append-only Operation Intent and Operation Outcome facts, synchronous workspace projections, cross-proof envelopes, hash-bound extensions, content-addressed proof bundles, and latest-schema-only data directories.

Detailed ADRs own the implemented algorithms and public proof boundaries.
