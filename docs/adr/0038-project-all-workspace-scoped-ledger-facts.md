# Project All Workspace-Scoped Ledger Facts

Workspace Projection includes workspace-scoped Operation Intents and Operation Outcomes rather than only completed outcomes. LicoLite needs workspace-scoped proof and recovery views to include open lifecycle states, while UI layers may choose how to present or filter them.

Repair Facts are reserved for a future repair executor. The current package does not append them, so current Workspace Projection docs must not claim Repair Facts are projected.
