# Enable Workspace Projections by Default for LicoLite

The LicoLite Aspect enables Workspace Projection by default and treats it as the first-priority path for LicoLite workspace proof and view needs. LicoLite is workspace-first, so Pactium provides verifiable workspace-scoped projections as a standard substrate capability rather than leaving LicoLite to filter the global ledger for workspace views.
