# Enable Workspace Projections by Default for LicoLite

The LicoLite Aspect will enable Workspace Projection by default and treat it as the first-priority path for LicoLite workspace proof and view needs. LicoLite is workspace-first, so Pactium must provide verifiable workspace-scoped projections as a standard substrate capability rather than leaving LicoLite to filter the global ledger for workspace views.
