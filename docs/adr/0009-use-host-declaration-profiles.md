# Provide a First-Class LicoLite Aspect

Pactium is a subordinate npm package whose primary purpose is to support LicoLite, so it includes a first-class LicoLite Aspect instead of treating LicoLite as an external plugin. LicoLite-specific entrypoints are grouped under the `pactium/licolite` package surface, and LicoLite requirements may directly shape Pactium core capability design.
