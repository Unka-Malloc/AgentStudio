Pact 系统架构图

从外观层到基建层展示 Pact 内部系统结构，重点表达控制面板、切面对接、服务能力、应用能力、公共基础设施和启动装配边界之间的关系。

历史基线：2026-05-19 状态：应用层 2 x 3 口径已固化 范围：Pact 内部结构
脱水状态 Essential Optional

外观层 Optional

Appearance
  • 控制面板面向个人用户展示知识库、工作空间、调试和系统管理界面。
  • 只通过切面层或服务层入口调用能力，不直接访问应用层运行时或基建层存储。
服务层

接口封装层 Essential

Interface Wrapper
  • 执行协议适配与请求归一化。
  • 认证、权限和接口合同来自基建与切面层。
  • 角色配置以 Tag 为基础语义，组织、小组和角色都继承自标签。
  • 认证管理作为服务能力，经切面合同装配。
  • 对上承接外观层，对下只调用装配后的能力。
