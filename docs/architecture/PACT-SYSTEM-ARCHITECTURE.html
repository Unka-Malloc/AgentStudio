Pact 系统架构图

从外观层到基建层展示 Pact 内部系统结构，重点表达控制面板、应用能力、切面对接、能力层、公共基础设施和启动装配边界之间的关系。

历史基线：2026-05-19 状态：外观层 / 应用层 / 切面层 / 能力层口径已调整 范围：Pact 内部结构
脱水状态 Essential Optional

外观层 Optional

Appearance
  • 控制面板面向个人用户展示知识库、工作空间、调试和系统管理界面。
  • 只通过应用层或切面层入口调用能力，不直接访问能力层运行时或基建层存储。
能力层

平台能力 Essential

Platform Capabilities
  • 汇聚平台能力、通信服务、协作治理、智能体运行能力和策略管理。
  • 角色配置以 Tag 为基础语义，组织、小组和角色都继承自标签。
  • 认证管理作为能力层能力，经切面合同装配。
  • 通信服务承载 ACP Relay 和 MCP Server Side，由切面层通过路由策略调用。
  • 协作治理把跨空间提案、锁、继承、共享授权和保留策略沉淀为可审计决策。
  • 智能体 runtime、上下文、记忆、模型网关和基础配置归入能力层。
  • 策略管理负责流程、调用、路由和门禁策略，不回流到应用层硬编码。
