# Pactium Terms

- `Pactium` — The protocol-layer framework in this repository.
- `Operation Ledger` — SQLite-backed operation record store.
- `Checkpoint Tree` — Append-only checkpoint tree with restore markers.
- `Merkle State Substrate` — Content-addressed storage, Merkle index, event log, state commit, and ingest ports.
- `Pactium Kernel` — Composition API that records one operation across ledger, checkpoint, and optional state commit.
- `PACTIUM_*` — Environment variable namespace used by Pactium.
- `~/.pactium` — Default local data directory.
